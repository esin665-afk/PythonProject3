## 📋 Описание проекта

Данный проект предоставляет набор функций для:

- ✅ **Маскирования** номеров банковских карт и счетов  
- ✅ **Преобразования** форматов дат  
- ✅ **Фильтрации** и **сортировки** транзакций  
- ✅ **Обработки** данных банковских операций
